### Anotaciones


<strong>ordinal()</strong> devuelve el index del planeta.

<strong>values()</strong> devuelve en un array todos los planetas.

<strong>EnumSet</strong> agrupa elementos de un enum.

<strong>EnumSet.range(inicio, fin)</strong> ambos inclusive.

<strong>private</strong> impide que la información de cada planeta sea modificada una vez creada la instancia.

<strong>Contructor del enum</strong>, debe de ser privado porque solo se tiene que crear una vez (Patrón Singleton).

<strongthis></strongthis> se refiere a una instancia en específico.

<strong>Notación científica</strong> 2,4397e+6, se interpreta como 2,4397^6.

<strong>name()</strong> devuelve el nombre como string.
